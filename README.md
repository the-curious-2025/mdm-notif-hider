# MDM Notification Hider

A Magisk module that automatically hides persistent notifications generated by device management applications on Android.

## Overview

Some Android device management applications (Device Admin / Device Owner) display persistent foreground-service notifications that cannot be dismissed through the notification shade.

Disabling notifications through Android Settings may not work because these notifications are tied to foreground services.

**MDM Notification Hider** addresses this by modifying the notification channel settings of selected management applications, setting their importance to `0` (NONE) and locking the relevant settings to prevent applications from restoring them.

The management applications and their services continue running normally. Only their notifications are suppressed.

## How It Works

The module operates during the `post-fs-data` stage of the Android boot process, before the Notification Manager loads its notification policy.

Its operation consists of three main steps:

1. **Identify target applications:** Reads `device_policies.xml` to identify registered Device Admin and Device Owner applications.
2. **Modify notification channels:** Updates the corresponding entries in `notification_policy.xml`, setting their importance to `0`.
3. **Lock notification settings:** Marks the modified channels as user-locked to prevent applications from automatically restoring their notification visibility.

Applications that are not registered as Device Admin or Device Owner can also be targeted manually by adding their package names to `targets.txt`.

## Installation

**Requirements**
- Android device with root access.
- Magisk installed.
- A compatible Android implementation and notification policy format.

**Steps**

1. Download the module ZIP from the [Releases](../../releases) page, or build it manually.
2. Open the Magisk application.
3. Navigate to **Modules → Install from storage**.
4. Select the downloaded ZIP file.
5. Reboot your device.

Allow up to two reboots for newly created notification channels to be detected and modified.

## Configuration

### targets.txt

Use `targets.txt` to specify additional applications that should have their notifications suppressed.

Add one Android package name per line.

This is useful for applications that are not registered as Device Admin or Device Owner.

## Backup and Recovery

During its initial execution, the module saves a backup of the original `notification_policy.xml` in its module directory.

To restore notification visibility:

1. Remove or disable the module through Magisk.
2. Reboot the device.
3. Open **Settings → Apps → [Target Application] → Notifications**.
4. Re-enable the relevant notification channels.

**Important:** Removing the module does not automatically restore notification channel settings. The changes are stored in Android's notification policy and must be reversed separately.

## Compatibility

Originally tested on:

- Android 11
- MediaTek (MTK) devices
- AOSP-based Android implementations
- Qin F21

Compatibility with other Android versions, manufacturers and ROMs has not been established.

Different Android versions and OEM implementations may use different notification policy formats or boot processes.

## Disclaimer

This module modifies Android's system notification policy.

- Root access is required.
- Incorrect modifications to system configuration files may cause unexpected behavior.
- Compatibility with every Android device is not guaranteed.
- Always maintain a backup before installing system-level modifications.

This module only targets notification visibility. It does not disable, remove, or interfere with the underlying functionality of management applications.
